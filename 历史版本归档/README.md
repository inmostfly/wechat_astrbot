# 历史版本归档

本目录集中保存 Catgirl 在采用微信 iLink 轻量客户端之前的实验代码，仅供回顾和学习，不参与当前版本的运行、安装、测试或打包。

## 目录内容

- `demo/`：最早期的 GPT 聊天机器人示例。
- `demo.py`：基于 `wxauto4` 的发送消息实验。
- `text.py`：基于 `wxauto` 与百度文心接口的微信实验。
- `wxauto/`：早期本地 wxauto 代码副本。
- `UIA/`：微信界面自动化版本及其测试、打包资料。
- `te.py`、`catgirl_qq.txt`：QQ 机器人实验及对应人设。
- `test_post.py`、`catgirl_blog.txt`：命令行模型调用实验及对应人设。

## 当前版本

当前使用的机器人位于项目根目录的 `ilink_catgirl/`。它通过微信 iLink 协议工作，并继续使用根目录的天气 MCP、联网 MCP、日志模块、测试和 `聊天助手.txt`，这些文件不属于历史归档。

归档中的代码可能依赖已经停用的接口、旧版微信结构或不再安装的依赖，不能作为当前部署入口。需要研究旧实现时，请单独创建虚拟环境，不要把归档依赖安装进线上环境。
