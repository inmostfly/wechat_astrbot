Catgirl 微信助手（目录版）
==========================

1. 确保桌面版微信已经登录。
2. 确保本文件旁边存在 .env，并已配置 API_KEY_2 等参数。源码运行时也可复用项目根目录的 .env。
3. 双击 Catgirl微信助手.exe。
4. 不要单独移动 EXE；整个 Catgirl微信助手 文件夹必须一起保留。
5. chat_logs 文件夹会在首次运行后自动创建。
6. 如果发生致命错误，程序会生成 crash_日期_时间_进程号.log，并保持控制台可见。
7. 阅读错误后按回车退出，也可以直接关闭控制台窗口。

和风天气：
- 天气 MCP 只使用和风天气。
- 必须在 .env 中配置 QWEATHER_API_KEY 和 QWEATHER_API_HOST。
- 未配置或和风接口异常时会明确报错，不会切换其他天气数据源。

注意：
- .env 含有 API Key。把程序发给别人前，请删除或替换 .env。
- 目标电脑不需要安装 Python 或 VS Code，但仍需安装并登录桌面版微信。
- 程序启动时会点击微信右上角的“置顶”按钮；退出后仍保留置顶状态。
- 程序不会循环抢夺键盘焦点，发送消息时才会临时聚焦输入框。
- 如果连 Python/PyInstaller 启动器都无法加载，程序代码尚未开始执行，此类系统级错误无法写入崩溃日志。
- 本 UIA 版本已归档；当前主线是项目根目录 ilink_catgirl 中的独立机器人轻量客户端。
