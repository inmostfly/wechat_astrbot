Catgirl 微信机器人 EXE 使用说明
================================

一、成品必须如何携带

本程序使用 PyInstaller onedir 方式打包。请复制或移动完整的“Catgirl微信机器人”文件夹，不能只拿走 Catgirl微信机器人.exe。

成品目录至少应保留：

Catgirl微信机器人\
├─ Catgirl微信机器人.exe
├─ _internal\                 程序依赖，不能删除
├─ .env                       个人 API 配置；可能需要自己创建
├─ .env.example               配置模板
├─ 用户自定义\               可直接编辑的文本配置
│  ├─ 聊天助手.txt           助手人格与行为要求
│  ├─ 主动问候语.txt         每行一条主动问候
│  └─ 定时提醒开场白.txt     每行一条提醒开场白
└─ EXE使用说明.txt

接收方不需要安装 Python，也不需要另外执行 pip install。Python 运行时和第三方依赖都在 _internal 文件夹中。

本次成品是在 64 位 Windows 环境构建的，建议在 64 位 Windows 10/11 使用。Windows 7 不属于保证兼容的目标系统。Ubuntu/Linux 不能运行这个 EXE，应使用项目源码和 Linux Python 环境。


二、第一次使用

1. 确认 Catgirl微信机器人.exe、_internal 和“用户自定义”文件夹仍在同一成品目录中。
2. 如果目录中没有 .env，请复制 .env.example，并把副本重命名为 .env。
3. 用记事本编辑 .env，至少填写：

   API_KEY_2=你的模型API密钥
   API_URL_2=https://api.deepseek.com
   MODEL_2=deepseek-v4-flash
   VISION_MODEL_2=deepseek-v4-flash-vision-exp

4. 天气查询还需要填写 QWEATHER_API_KEY 和 QWEATHER_API_HOST。
5. 联网搜索可填写 TAVILY_API_KEY，或者填写自建的 SEARXNG_URL。
6. 需要邮箱查询或新邮件通知时，参照 .env.example 填写 EMAIL_IMAP_*。Gmail 的 password 模式必须使用应用专用密码，不能使用普通 Google 密码；保持 EMAIL_MONITOR_ENABLED=false 即不会自动监听。
7. 需要接入其他 stdio MCP 时，复制 mcp_servers.example.json 为 mcp_servers.json，并只把允许模型使用的工具写进 allowed_tools。
8. 双击 Catgirl微信机器人.exe。第一次运行会生成 data\weixin-login.png，并在控制台显示备用扫码链接。
9. 使用手机微信扫码并确认。成功后登录状态保存在 data\session.json，下次通常无需重新扫码。

注意：.env 和 data\session.json 都含敏感信息，不能上传到公开仓库或发送给他人。


三、日常使用

保持控制台窗口运行，机器人才能在线。

- 普通聊天：直接在微信发送文字。
- 天气：例如“查询河南省邓州市未来3天天气”。
- 联网：例如“联网搜索某个内容”，或直接发送公开网址。
- 图片识别：直接发送 JPEG、PNG、GIF 或 WebP 图片。
- 文档阅读：直接发送 PDF、DOCX、XLSX、XLSM、PPTX、TXT、Markdown、CSV、JSON、XML、YAML、HTML 等文件。
- 文档追问：文件得到首次摘要后，可继续问“第三章讲了什么”“表格里最高分是谁”等问题。
- 提醒：例如“10分钟后提醒我休息”“每天7点30分发送邓州天气”“每周一和周五20点30分提醒我交周报”。
- 邮箱：启用邮箱 MCP 后可问“查看最近邮件”；启用监听后，新邮件摘要会在微信主动下发额度可用时自动送达。

扫描版 PDF 如果没有文字层，目前不能自动 OCR。旧式 .doc、.xls、.ppt 应先转换为 .docx、.xlsx、.pptx。


四、安全停止

在控制台输入以下任意命令后按回车：

quit
exit
stop
退出
停止

程序会保存游标并安全下线。尽量不要直接关闭窗口或强制结束进程。


五、运行数据和故障排查

程序会在 EXE 同目录生成：

- data\session.json：微信登录状态、消息游标和去重信息。
- data\reminders.sqlite3：提醒任务数据库。
- data\email_cursor.json：最后成功通知的邮件 UID，用于重启去重。
- logs\chat_日期_时间.log：本次聊天与工具调用日志。
- logs\crash_日期_时间.log：未处理致命错误的完整堆栈。

如果启动后报错：

1. 不要删除 _internal。
2. 检查 .env 是否存在、API_KEY_2 是否正确。
3. 查看窗口最后一行和 logs\crash_*.log。
4. 文档读取失败时，先检查格式、大小、是否加密，以及 PDF 是否只有扫描图片。
5. 登录失效时备份日志，然后删除或移走 data\session.json，重新启动并扫码。

Windows 遇到致命错误时，程序默认会等待按回车关闭窗口，避免错误信息一闪而过。可在 .env 使用 PAUSE_ON_ERROR=false 关闭等待。


六、自定义人格与消息话术

成品目录中的“用户自定义”文件夹专门留给用户编辑，不需要修改 Python 代码：

- 聊天助手.txt：完整的人格、称呼、表达风格和行为要求。这里的内容会作为模型的系统提示词。
- 主动问候语.txt：每个非空、非 # 注释行是一条候选问候，程序会随机选择。行首的“1.”“2、”等编号会自动去掉。
- 定时提醒开场白.txt：每个非空、非 # 注释行是一条候选开场白，普通提醒和天气提醒到点时随机选择；它本身不消耗模型 API。

请用支持 UTF-8 的文本编辑器修改，保持文件名不变。保存后需要退出并重新启动 EXE，新的内容才会重新加载。.env 用于 API、天气、联网和程序参数，不用于编写人格。

程序优先读取“用户自定义”文件夹；某个文件被误删时，会退回打包时内置的默认版本。因此升级前建议备份整个“用户自定义”文件夹，再把自己的版本放回新版成品中。


七、迁移与分享

- 迁移到另一台 Windows 电脑：复制整个“Catgirl微信机器人”文件夹。
- 保留原登录和提醒：同时复制 data 文件夹，并妥善保护其中的凭据和数据库。
- 不保留原登录：发送前删除 data 文件夹，让使用者重新扫码。
- 分享给别人：必须先删除 .env、data 和 logs，避免泄露 API Key、微信登录态和聊天内容。
- 更新版本：先备份 .env、data 和“用户自定义”，再用新版完整成品替换程序文件，最后把个人文件放回成品目录。

完整原理和服务器部署说明可查看同目录 README.md 与“独立机器人轻量客户端技术文档.md”。
